# Changelog

Registro de cambios de HUMANO. El formato se inspira en Keep a Changelog.

## [1.0.0] - 2026

### Added

- Definición formal del framework HUMANO.
- Seis dimensiones metodológicas H-U-M-A-N-O.
- Metodología documentada.
- Caso demostrativo Adult Census.
- Notebook reproducible en Kaggle.
- Auditoría por grupos.
- Métricas Accuracy, Selection Rate, FPR y FNR.
- Comparación de modelo con y sin atributos sensibles.
- Exportación de resultados en JSON.
- Sincronización automática Kaggle → GitHub.
- Visor interactivo mediante GitHub Pages.
- Documentación metodológica.
- CITATION.cff.
- Licenciamiento diferenciado para código y documentación.

### Notes

Esta es la primera versión estable de HUMANO.

El DOI oficial se añadirá después de la publicación en Zenodo.
