Las seis dimensiones

Cada letra de HUMANO representa una pregunta que debe responderse antes de aprobar un sistema de inteligencia artificial.

H

Humanizar el propósito

¿Para qué se utilizará la IA y qué consecuencias puede producir?

Se analiza qué variable intenta predecir el modelo, para qué podría utilizarse y cuáles serían las consecuencias de una predicción incorrecta. En el laboratorio Adult Census, una predicción errónea de ingresos podría afectar decisiones de crédito, empleo o acceso a servicios.

U

Ubicar personas e impactos

¿Quién está representado y quién puede verse afectado?

Se explora la representación de grupos en los datos: distribución por sexo, categoría racial y diferencias en los resultados observados. Grupos minoritarios pueden estar sub-representados y recibir predicciones menos precisas.

M

Minimizar datos y riesgos

¿Qué datos son realmente necesarios y qué riesgos pueden introducir?

Se revisan atributos sensibles (sexo, raza), variables potencialmente innecesarias y posibles relaciones indirectas o proxies que puedan reintroducir sesgos incluso si se eliminan los atributos sensibles.

A

Asegurar autonomía y transparencia

¿Podemos explicar y cuestionar las decisiones del sistema?

Se construye una regresión logística y se analizan las variables con mayor influencia, los coeficientes del modelo y la capacidad de explicar las predicciones. Un modelo explicable permite que las personas afectadas cuestionen las decisiones.

N

Nombrar responsables

¿Quién responde por los datos, el modelo y sus decisiones?

Se propone una estructura de gobernanza que identifica responsables para: propósito del sistema, datos, desarrollo, validación, decisiones, reclamaciones y monitoreo.

O

Observar, auditar y corregir

¿El sistema funciona de manera consistente entre grupos y qué hacemos cuando encontramos diferencias?

Se calculan métricas globales y por grupos (Accuracy, Selection Rate, FPR, FNR) y se compara un modelo con atributos sensibles contra uno sin ellos, demostrando que eliminar variables no es suficiente.

Caso demostrativo · Adult Census

El laboratorio utiliza el dataset Adult Census Income del UCI Machine Learning Repository como caso educativo.

Objetivo técnico: predecir si el ingreso anual de una persona supera USD 50.000.

⚠ Este ejercicio no recomienda utilizar este modelo para tomar decisiones reales sobre personas.

Fuente: UCI Adult Dataset · DOI: 10.24432/C5XW20
